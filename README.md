### 📝 Sobre o Projeto

Este sistema web foi idealizado para atender às necessidades reais de uma madeireira. O objetivo é entregar uma aplicação robusta que une um catálogo digital interativo para os clientes a um painel de controle administrativo eficiente para a gestão interna do negócio.

---

### 🛠️ Tecnologias Utilizadas

O projeto foi construído do zero utilizando tecnologias nativas da web:

* **HTML5** — Estruturação semântica de todas as páginas e formulários.
* **CSS3** — Estilização, layout responsivo e identidade visual moderna com toque rústico.
* **JavaScript** — Interatividade em tempo real, máscaras de campos e validações no cliente.
* **PHP** — Processamento no servidor, regras de negócio, controle de sessões e backend.

---

### ⚙️ Funcionalidades Principais

* 🛒 **Catálogo Online:** Exibição de produtos (vigas, tábuas, painéis) com filtros de busca rápidos.
* 📐 **Calculadora de Medidas:** Simulação de metros cúbicos ou peças necessárias para o cliente.
* 🔐 **Painel Administrativo:** Área restrita para controle de estoque e gerenciamento de produtos.
* ✉️ **Sistema de Orçamentos:** Formulário integrado para captação direta de pedidos.
