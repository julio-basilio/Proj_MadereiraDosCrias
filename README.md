## 📖 Sobre o Projeto

A **Madeireira dos Crias** é uma plataforma web desenvolvida para modernizar o atendimento e a gestão de uma madeireira.

O sistema integra um **catálogo digital interativo**, voltado para clientes, com um **painel administrativo completo**, permitindo o gerenciamento eficiente de produtos, estoque e solicitações de orçamento.

Nosso objetivo é unir tecnologia e praticidade para transformar processos tradicionais em experiências digitais simples, rápidas e intuitivas.

---

## 🎯 Objetivos

✅ Facilitar a consulta de produtos pelos clientes.

✅ Automatizar o controle de estoque.

✅ Centralizar pedidos de orçamento.

✅ Melhorar a organização administrativa.

✅ Aplicar conhecimentos de Programação Web em um projeto real.

---

## 🚀 Funcionalidades

### 🛒 Catálogo Online
- Visualização de produtos em tempo real.
- Busca rápida por nome ou categoria.
- Interface intuitiva e responsiva.

### 📐 Calculadora de Medidas
- Cálculo automático de volume em m³.
- Simulação de quantidade de peças necessárias.
- Auxílio para planejamento de compras.

### 🔐 Painel Administrativo
- Login protegido por autenticação.
- Cadastro, edição e remoção de produtos.
- Controle e atualização de estoque.

### ✉️ Sistema de Orçamentos
- Solicitação de orçamento online.
- Envio de informações diretamente para análise.
- Agilidade no atendimento ao cliente.
